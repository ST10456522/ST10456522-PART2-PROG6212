# part2POE
Raceday Management API

Raceday is an ASP.NET Core Web API developed using C# and SQL Server. The system manages race events, participants, organisers, categories, enrolments, and race results. It includes user registration and login for participants and organisers, allowing organisers to manage events and participants to enrol in races. The project also includes unit tests to verify key system functionalities.
